HashLife Parallel computes the same patterns as HashLife, using several threads. It supports the same rules as HashLife.

Each step is split into pieces of work that the threads share. Patterns whose steps take more than a few milliseconds gain the most; very small steps can be slower than with HashLife.

The number of threads is set in Preferences > Control (the default is the number of CPUs). A new value is used by universes created afterwards, for example after opening a pattern or changing the algorithm.

While one step is being computed, Golly does not respond to input; it responds between steps. With a large step size, a single step can take a long time.
