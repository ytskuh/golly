QuickLife CUDA computes the same patterns as QuickLife, on an NVIDIA graphics card. It supports the same rules as QuickLife. It is available only in builds of Golly made with CUDA support.

The graphics card computes generations of outer-totalistic rules (B.../S... rules, including B0 rules) on unbounded grids. Other rules, bounded grids, and computers without a usable NVIDIA card use QuickLife on one thread.

The cells are copied back from the graphics card whenever Golly needs them, for example to display the pattern after each step. For large patterns that copy can take longer than the generations, so larger step sizes make better use of the card.
