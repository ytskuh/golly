QuickLife Parallel computes the same patterns as QuickLife, using several threads. It supports the same rules as QuickLife.

It times generations computed by one thread and by all, half, a quarter or an eighth of the threads, and uses whichever was fastest lately, so small patterns run at about the speed of QuickLife.

The number of threads is set in Preferences > Control (the default is the number of CPUs). A new value is used by universes created afterwards, for example after opening a pattern or changing the algorithm.
